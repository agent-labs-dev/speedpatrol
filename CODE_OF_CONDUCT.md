# Code of conduct

Speedpatrol follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep criticism about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

To report a problem, use GitHub's **Report content** option on the comment or issue, or contact a maintainer privately through their GitHub profile. Maintainers review every report, keep the reporter's identity private, and may remove content or block accounts that break this code.
